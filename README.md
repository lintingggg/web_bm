# Web Profile CMS

Repositori ini berisi source code untuk sistem Content Management System (CMS) dan Website Profil Publik (termasuk modul Profil, Mars BM, Logo BM, Struktur Organisasi, Artikel, Galeri, dan Agenda). 

Proyek ini dirancang agar pengurus atau admin dapat dengan mudah memperbarui informasi publik, jadwal kegiatan, serta dokumentasi secara dinamis tanpa perlu mengubah kode sumber.

## Fitur Utama

- **Halaman Profil Dinamis**: Menampilkan informasi lembaga seperti Tentang Kami, Struktur Organisasi, Mars BM, dan Logo BM.
- **Manajemen Konten (CMS)**: Fitur untuk membuat, mengedit, dan menghapus Artikel/Berita dan Galeri foto.
- **Agenda & Jadwal**: Menampilkan daftar agenda dan jadwal kegiatan yang akan datang.
- **Integrasi Media Sosial**: Menampilkan sematan (embed) dari media sosial secara langsung di website.
- **Dashboard Admin**: Panel kontrol (backend) yang user-friendly untuk mengelola seluruh data website.

## Teknologi Utama

- **Framework Backend**: Laravel
- **Framework Frontend**: React.js dengan Inertia.js
- **Styling**: Tailwind CSS
- **Database**: MySQL / PostgreSQL (didukung oleh Laravel Eloquent)
